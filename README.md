# VIS-IOS

Welcome to the **VIS-IOS** repository!

This project is the official iPhone app for Visual Aerial Advertising. VIS-IOS allows clients to follow their banner towing flights in real time, receive notifications about campaign activity, and access flight details directly from their mobile device.

![App Screenshots](image2)

## About VISUAL

VISUAL delivers real-time tracking and management for aerial advertising campaigns. The iPhone app provides users with instant updates, interactive maps, and status alerts to maximize campaign visibility and engagement.

## Features

- **Real-Time Flight Tracking:** Follow your banner towing flights live on the map.
- **Campaign Notifications:** Receive alerts about campaign activity and flight status.
- **Flight Details:** Access information about aircraft, pilots, and banner assignments.
- **User Profiles:** Manage your account and view your campaign history.
- **Interactive UI:** Enjoy a modern and intuitive interface for effortless navigation.

## Getting Started

To set up VIS-IOS locally for development:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/itseduvieira/vis-ios.git
   ```
2. **Open in Xcode:**
   - Launch Xcode and open the cloned project folder.

3. **Install Dependencies:**
   - If using CocoaPods or Swift Package Manager, install necessary packages:
     ```bash
     pod install
     ```
     or follow instructions in the repo.

4. **Build & Run:**
   - Build and run the app on a simulator or physical iPhone device.
